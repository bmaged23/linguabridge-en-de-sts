# Reproduce the local TTS comparison

Stop the voice server before these GPU tests. The benchmark never reads or changes conversation history and makes no cloud LLM calls. Model downloads require a network connection. Keep checkpoints on a drive with enough free space; this machine uses D: through `/mnt/d/voice-bridge-models`.

The deployed `.venv` and `.venv-asr` environments must already exist. The test overlay reuses `.venv-asr` dependencies without changing them:

```bash
uv venv .venv-qwen-tts --python .venv-asr/bin/python
.venv-qwen-tts/bin/python - <<'PY'
from pathlib import Path
import sysconfig
Path(sysconfig.get_paths()['purelib'], 'shared-asr-dependencies.pth').write_text(
    str(Path('.venv-asr/lib/python3.12/site-packages').resolve()) + '\n'
)
PY
uv pip install --python .venv-qwen-tts/bin/python --no-deps -r requirements/archive/qwen-tts-evaluation.txt
```

Download `Qwen/Qwen3-TTS-12Hz-0.6B-Base` at revision `5d83992436eae1d760afd27aff78a71d676296fc` into `/mnt/d/voice-bridge-models/qwen3-tts-0.6b`, including its `speech_tokenizer` subdirectory. The independent Whisper scorer is `dropbox-dash/faster-whisper-large-v3-turbo` at revision `0a363e9161cbc7ed1431c9597a8ceaf0c4f78fcf`, stored at `/mnt/d/voice-bridge-models/faster-whisper-large-v3-turbo`. Local ASR weights remain at `models/qwen3-asr-0.6b`. Use Hugging Face `snapshot_download(..., revision=..., local_dir=...)` to avoid duplicating downloads in a second blob cache.

Run sequentially to release GPU memory between stages:

```bash
.venv-tts-gpu/bin/python -m scripts.application.start_voice_app -m scripts.evaluation.compare_speech_synthesis baseline
.venv-qwen-tts/bin/python -m scripts.evaluation.compare_speech_synthesis qwen --dtype float32
.venv-qwen-tts/bin/python -m scripts.evaluation.evaluate_qwen_tts_memory
.venv-asr/bin/python -m scripts.evaluation.compare_speech_synthesis judge --dtype float32 --scorer qwen
.venv/bin/python -m scripts.application.start_voice_app -m scripts.evaluation.compare_speech_synthesis judge --dtype float32 --scorer whisper
.venv/bin/python -m scripts.reports.export_synthesis_comparison
.venv/bin/python -m scripts.application.start_voice_app
```

`compare_tts.py qwen --model /another/checkpoint/folder` overrides the test checkpoint path. Other default paths describe this machine and can be adjusted in the fit/scorer scripts. The `.venv-qwen-tts` overlay is local and ignored by Git; recreate it if the checkout moves.

Fixed cases are in `scripts/evaluation/speech_synthesis_test_cases.json`. Qwen uses the synthetic Kokoro reference generated by the baseline stage, one warmup, cached reference features, a fixed seed, explicit languages for monolingual/spliced conditions, automatic language for the mixed whole-text condition, and checkpoint sampling defaults with `max_new_tokens=512`. Each complete sample is measured once. The additional co-residency helper extracts an internal speaker-embedding diagnostic and tests real ASR and TTS speech inference while both models are resident; it does not test simultaneous GPU generation. Generation time excludes initialization, voice-reference extraction, file writing and monitoring teardown. GPU/CPU/RAM are sampled during generation.

Stages resume existing completed rows with audio. To intentionally rerun a stage after changing its settings, first move its output JSON/audio aside; do not mix runs under the same variant name. Scorers record audio SHA256 hashes. Both compare identical waveform files and use the same case/punctuation normalization. Reference text is supplied only to the scorer's error-count calculation, never to ASR decoding.

The original FP16 eager run failed during warmup with invalid sampling probabilities on the GTX 1660 Ti. It produced no valid scored samples. See `compatibility.json`; FP16 cannot be assigned a meaningful WER/CER from that failed run. The Qwen SDK call here returns complete waveforms, so the reported first-available-audio measurement is not true streaming audio latency.
