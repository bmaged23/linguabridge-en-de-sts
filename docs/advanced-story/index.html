Confirmed problems

  • STT sometimes translates or repeats speech instead of preserving both languages.
  • Pauses and the 30-second turn cap can cancel recorded input before its final transcript.
  • Five bilingual replies omitted voice markers, sending both languages through one voice.
  • Earlier conversation memory can conceal missing current input and repeat unconfirmed inferences.
