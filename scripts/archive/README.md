# Historical audit orchestration

These two scripts coordinated the October 2026 base/extended story evaluations and standard-window ASR controls. They are preserved for research provenance, with imports and paths updated to the current layout.

They contain fixed run names, waits for previously generated results, GPU ownership changes and app restarts. They are not the general-purpose test entrypoints for a fresh clone. Use the [continuous story test guide](../../docs/guides/advanced-story-testing.md) and `scripts.story_tests.run_story_pipeline_tests` for new runs.
